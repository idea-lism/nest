# AGENTS.md

Must read [specs/agents/RULES.md](specs/agents/RULES.md) before changing code.

When reviewing code, must also read [specs/agents/review.md](specs/agents/review.md).

Implementations must follow specs. Specs are the user's area: propose changes, don't rewrite them unilaterally.

## Current state

Refactor in progress. The old LLVM IR backend, PEG backend, token tree, and `nest` CLI are removed. Only the reusable core and its tests are built. `src/g4.c`, `src/g4.nest`, `benchmark/`, `examples/`, and `test/examples/` are kept for later phases but are not built or run.
